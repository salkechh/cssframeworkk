# Парсинг и защита от парсинга 
  Данный учебный веб-проект представляет собой тематический сайт из 10 страниц, посвященный технологиям автоматизированного сбора данных в интернете и методам противодействия им. 
## Описание проекта
  Проект разработан с целью демонстрации навыков Frontend-разработки (верстки). В рамках контента рассматриваются:
  - Базовые концепции (разница между краулингом и скрапингом).
  - Инструментарий разработчика (Beautiful Soup, Scrapy, Puppeteer, Selenium).
  - Продвинутые техники парсинга (ротация прокси, XHR reverse engineering).
  - Системы защиты (WAF, Cloudflare) и методы обхода CAPTCHA.
  - Правовые и этические аспекты сбора данных.
## Используемые технологии
  Проект реализован с упором на чистую семантику, адаптивность и скорость работы:
  - HTML5: Семантическая, валидная разметка (с использованием тегов `header`, `main`, `aside`, `footer`, `article`).
  - CSS3: Кастомные стили поверх легковесного CSS-фреймворка Cirrus UI (https://cirrus-ui.netlify.app/). Использован подход адаптивной верстки (Responsive Web Design).
  - JavaScript (Vanilla JS): Реализация базового интерактива (адаптивное бургер-меню для мобильной версии).
## Инструкция по запуску
  Проект представляет собой классический статический веб-сайт. Для его работы не требуется установка локального сервера или баз данных.
  Локальный запуск:
  1. Склонируйте репозиторий или скачайте архив с кодом.
  2. Распакуйте архив в любую директорию.
  3. Откройте файл index.html в любом веб-браузере. Навигация по страницам будет работать автоматически.
